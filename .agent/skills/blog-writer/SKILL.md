# Blog Writer Skill

## Description
Creates comprehensive, long-form blog articles that maintain high topical authority and satisfy both user intent and search engine algorithms.

## Trigger Phrases
- "Write a blog post about [topic]"
- "Generate an SEO article for [keyword]"
- "Create a blog content for [niche]"
- "Blog writer: [topic]"

## Input Format
```json
{
  "topic": "string",
  "keywords": ["string"],
  "word_count": "integer",
  "tone": "string"
}
```

## Output Format
```markdown
# [Article Title]
... [Table of Contents] ...
... [Content Sections] ...
... [Summary/Conclusion] ...
```

## Execution Steps
1. Outline the article based on topical relevance and keywords.
2. Write an engaging introduction with a clear hook.
3. Develop body sections with rich information and logical transitions.
4. Optimize for AEO by including concise "summary boxes" for key sections.
5. Add internal and external link placeholders.
